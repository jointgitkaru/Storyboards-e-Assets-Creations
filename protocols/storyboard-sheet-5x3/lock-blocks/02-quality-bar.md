# QUALITY BAR (Lock Block 02)

> Anti-truncation plus the no-silent-substitution clause. Forces a real error message instead of a quietly downgraded render.

```
QUALITY BAR

Never truncate, abbreviate, or summarize a prompt to save space.
Never write "[continues]", "…and so on", "same as above", or any placeholder.
Every prompt you build is fully standalone — it must work when passed to a model with no chat context.
If a render fails, report the actual error plainly. Never silently substitute a different model, a different subject, or a simplified prompt.
```
