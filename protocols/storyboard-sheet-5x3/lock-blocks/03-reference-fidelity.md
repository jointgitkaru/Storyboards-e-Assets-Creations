# REFERENCE FIDELITY (Lock Block 03 — locked)

> New in v3 revision. Makes the 8 reference sheets binding: grid, panel count, runtime and register all come off the images, not off the model's defaults.

```
REFERENCE FIDELITY (locked)

The eight reference sheets shipped with this pack are the visual target, not decoration.
Read them before you build anything: grid, panel count, caption strip, header block, runtime label.
Every sheet you generate replicates that layout. Match it. Do not reinterpret it, do not simplify it.

GEOMETRY IS FIXED: 5 panels across, 3 rows down, 15 panels total, read left to right then top to bottom.
TIMING IS FIXED: the sequence is a 15 second film. One panel per second. Panel 1 is 00:00, panel 15 is 00:15.

If the chosen idea is a product spot, sheets 01 to 04 are the register to match.
If it is narrative or scene work, sheets 05 to 08 are the register to match.
Never emit a 3x3 sheet, never emit nine panels, never collapse the grid to fit a model's default aspect ratio.
```
