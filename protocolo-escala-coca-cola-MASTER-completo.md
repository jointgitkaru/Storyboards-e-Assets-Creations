# MASTER PROMPT COMPLETO — Coca-Cola Dimensional Scale Reference 2x2 (v1.0)

> Este é o arquivo de referência completo. Use o `protocolo-escala-coca-cola-v1.md` no dia a dia.

## PROMPT COMPLETO

```
Create a professional 2×2 dimensional scale reference sheet using the attached
reference image as the ONLY visual source of truth for the appearance of the subject.

The primary purpose of this image is ACCURATE PHYSICAL PROPORTION REFERENCE,
NOT artistic interpretation.

==================================================
MANDATORY SCALE REFERENCE — COCA-COLA CAN
==================================================
Use ONE standard 33 cl Coca-Cola Classic can as the fixed dimensional reference
object in EVERY panel.

The can MUST have these exact physical dimensions:
- Total height: 11.5 cm
- Body diameter: 6.6 cm
- Top/lid diameter: 5.2 cm
- Capacity: 33 cl

These dimensions are FIXED and MUST NOT be altered, stretched, compressed, or
approximated. The can must remain physically consistent in all four panels.

The Coca-Cola can must be positioned beside the subject at a real-world physical
distance of approximately 5–10 cm from the nearest point of the subject.

The can and the subject MUST occupy the same physical ground/reference plane
whenever the subject is standing, sitting, lying, or otherwise resting on a surface.

DO NOT place the can closer or farther away merely to make the composition
visually attractive.

==================================================
DIMENSIONAL CALCULATION — ABSOLUTE REQUIREMENT
==================================================
The subject's physical dimensions MUST be calculated relative to the fixed
11.5 cm can height.

DO NOT visually estimate the subject's size.
DO NOT invent dimensions.
DO NOT normalize or resize the subject independently between panels.
DO NOT make the can larger or smaller to compensate for composition.

The ratio between subject and can must correspond to their actual physical
dimensions.

Example: if the subject is 33 cm tall → 33 ÷ 11.5 = 2.87 → subject must be
exactly 2.87× the height of the can.

Apply the same principle to: height, width, depth, body length, wingspan,
limb length, tail length, object diameter, object thickness, overall bounding
dimensions, and any other measurable physical dimension relevant to the subject.

All dimensions must maintain their real-world ratios relative to the 11.5 cm can.

==================================================
DIMENSIONAL INPUT GATE — DO NOT GUESS
==================================================
Before generating the image, determine whether sufficient real-world
measurements are available.

FOR HUMAN OR NON-HUMAN CHARACTERS:
The required physical measurements MUST be explicitly provided before generation.
At minimum, ask for:
1. Total standing height from ground to highest point.
2. Overall body length, when applicable.
3. Overall width, when applicable.
4. Overall depth, when applicable.
For animals/creatures, also ask for any relevant characteristic dimensions.
If the character is normally measured in another pose, ask for the appropriate
reference measurement.
If the user has NOT supplied sufficient measurements: STOP. DO NOT INVENT A
DIMENSION. ASK THE USER FOR THE MISSING REAL-WORLD MEASUREMENTS FIRST.

FOR OBJECTS:
If the object is measurable but its dimensions have not been provided, DO NOT
GUESS. The dimensions MUST be verified through a reliable source before
generation. If the object has multiple versions, models, generations, or sizes,
identify the exact version before calculating the scale. If reliable dimensional
information cannot be established, STOP and ask the user for exact dimensions.
Never substitute an assumed "typical" size. Never use visual intuition as a
dimensional measurement.

==================================================
REFERENCE IMAGE FIDELITY
==================================================
If a reference image is provided, preserve the subject's identity and physical
appearance as accurately as possible. The reference image is the ONLY source
of truth for: species, breed, anatomy, body proportions, silhouette, facial
structure, coloration, markings, surface characteristics, clothing (if
applicable), accessories (if applicable), distinctive physical traits.

DO NOT redesign, beautify, stylize, anthropomorphize, or cartoonify the subject.
DO NOT alter its proportions to make the composition easier.

==================================================
2×2 GRID
==================================================
Create ONE unified 2×2 dimensional reference sheet containing four panels.
The SAME subject and the SAME Coca-Cola can must appear in all four panels.

Panel 1: Front view / primary reference view.
Panel 2: Three-quarter view.
Panel 3: Side/profile view.
Panel 4: Rear or alternate three-quarter view.

If the user's requested poses/views are specified, follow those exact views
instead. The subject must retain the same physical dimensions in every panel.
The Coca-Cola can must retain the exact same physical dimensions in every panel.

==================================================
CAMERA — MANDATORY HORIZONTAL SETUP
==================================================
Use a HORIZONTAL camera orientation in every panel. The camera must remain
level with the subject. Use the same camera height, focal length, perspective
characteristics, and approximate camera distance across all panels whenever
physically possible.

Do NOT use an extreme wide-angle lens. Avoid perspective distortion. Use a
naturalistic, low-distortion photographic perspective suitable for dimensional
comparison. The camera must NOT be tilted vertically. Do NOT use an overhead
camera. Do NOT use a low-angle perspective that artificially changes apparent
proportions. Do NOT use forced perspective.

The Coca-Cola can and subject must be photographed/rendered from the same
camera position and focal characteristics within each panel.

==================================================
PHYSICAL SCALE CONSISTENCY
==================================================
The can is the MASTER SCALE OBJECT. Its physical dimensions are ALWAYS:
11.5 cm tall, 6.6 cm body diameter, 5.2 cm top/base diameter.

Every subject dimension must be derived from its actual physical measurement.
The visual size of the can relative to the subject must therefore change ONLY
when the subject's actual physical dimensions change. The can itself must
NEVER change size between panels. Maintain consistent physical scale across
the entire sheet. The pose may change apparent vertical extent, but the
underlying physical dimensions of the subject MUST remain unchanged.

==================================================
CAN POSITION
==================================================
Place the Coca-Cola can beside the subject. Target physical separation: 5–10 cm.
Prefer approximately 7 cm when no other instruction is provided. Measure this
distance from the nearest physical surface of the subject to the nearest
surface of the can — not from the center of the subject.

Do NOT overlap the can with the subject. Do NOT place the can behind the
subject. Do NOT use forced perspective to make the can appear closer. The can
must remain clearly visible and unobstructed.

==================================================
GROUNDING AND CONTACT
==================================================
The subject and can must obey realistic physical contact and gravity.
- Standing subjects: both subject and can rest on the same ground plane.
- Sitting subjects: subject remains physically grounded, can remains upright
  on the same surface.
- Lying subjects: subject remains naturally grounded, can remains upright
  beside it unless otherwise requested.
- Walking subjects: can remains stationary on the ground while the subject
  passes beside it.

Do not float either object. Do not alter scale because of pose.

==================================================
VISUAL STYLE
==================================================
Professional photographic dimensional reference sheet. Neutral studio
environment. Plain neutral gray background. Soft, even, diffuse lighting.
Natural realistic shadows. High anatomical and geometric fidelity. Natural
photographic texture. Subtle organic photographic grain. Realistic materials
and surface detail. No artistic distortion, no exaggerated perspective, no
cinematic forced perspective, no fisheye effect, no fantasy scaling.

==================================================
DIMENSION ANNOTATIONS
==================================================
If measurement annotations are requested, display them clearly and accurately
in centimeters. Show the subject's verified primary dimension and the can's
fixed 11.5 cm height. Any annotation must represent the actual calculated
physical dimension. NEVER display a measurement that was not supplied or
verified. If measurements are not requested, do not add labels, rulers,
arrows, grids, text, or dimension lines.

==================================================
ABSOLUTE PROHIBITIONS
==================================================
DO NOT guess or approximate dimensions.
DO NOT alter or resize the Coca-Cola can's dimensions per panel.
DO NOT resize the subject per panel.
DO NOT use forced perspective or different scales between panels.
DO NOT distort, stretch, or compress the subject's anatomy or proportions.
DO NOT change the subject's identity.
DO NOT replace the can with another beverage container, format, or size
(no mini can, slim can, tall can, glass bottle, or generic cylindrical
container). The reference can MUST correspond to the standard 33 cl
Coca-Cola Classic can dimensions specified above.

==================================================
FINAL VALIDATION BEFORE GENERATION
==================================================
Before generating the image, internally verify:
1. Subject dimensions are known or reliably verified.
2. Coca-Cola can height = exactly 11.5 cm.
3. Coca-Cola can body diameter = exactly 6.6 cm.
4. Coca-Cola can top/base diameter = exactly 5.2 cm.
5. Subject-to-can scale ratio has been calculated.
6. Can-to-subject physical distance = 5–10 cm.
7. Same physical scale is maintained across all four panels.
8. Camera orientation is horizontal.
9. Perspective distortion is minimized.
10. Subject identity and proportions match the reference.
11. No unverified dimensions have been invented.

If ANY required dimensional information is missing: DO NOT GENERATE THE IMAGE.
ASK FOR THE MISSING MEASUREMENT(S) FIRST.
```

## Exemplo real (gato siamês, 33 cm)

```
SUBJECT DIMENSIONS:
Subject: Male Siamese cat shown in the attached reference image.
Verified standing height: 33 cm from floor to the highest point of the ears.

Coca-Cola Classic 33 cl can:
Height: 11.5 cm | Body diameter: 6.6 cm | Top/base diameter: 5.2 cm

Required subject-to-can distance: 5–10 cm (preferred: 7 cm)
The 33 cm standing height must remain the physical master dimension of the
cat across every pose.

Ratio: 33 ÷ 11.5 = 2.87 → the cat is exactly 2.87× the height of the can.
```
